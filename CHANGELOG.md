# MobBy changelog

## 1.1.0 · 25 November 2026

MobBy 1.1.0 is the official release name for the implementation tested as 1.2.0-dev1. The Gradle version, plugin descriptor, JAR manifest, runtime version display and distribution filenames now use 1.1.0.

The release retains biome-aware spawning, unattended farm operation, the 2,000-block region ceiling, shared chunk tickets, region persistence and recovery of managed mobs. See [release verification](TEST-REPORT-1.1.0.md) and the [candidate soak results](SOAK-REPORT-1.1.0.md).

The archived changelog also contains an earlier development-history entry labelled 1.1.0 on 17 November. The release dated 25 November is identified by the JAR fingerprint in its checksum manifest. [Archived changelog](docs/history/1.2.0-dev1/CHANGELOG.md)
